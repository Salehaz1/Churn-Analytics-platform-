# Customer Churn Analytics Platform

Enterprise-grade Streamlit application for customer churn analytics, executive reporting, supervised churn modeling, manual prediction, and customer segmentation.

## Run

```bash
python3 -m pip install -r requirements.txt
streamlit run app.py
```

## Workflow

1. Dataset Upload
2. Data Exploration & Cleaning
3. Executive Dashboard
4. Machine Learning Analytics

The app preserves the notebook's core Telco churn workflow: churn preprocessing, balanced Logistic Regression production scoring, model comparison, KMeans/PCA segmentation, revenue-at-risk analysis, risk levels, priority scoring, and retention offers.
